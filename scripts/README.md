# Maintenance tools

One uv-managed Python package, `homelab-tools`, contains the maintenance commands.
Runtime dependencies and console entry points belong in `pyproject.toml`;
`uv.lock` is generated by `uv lock --project scripts`.

## Development

From the repository root:

```sh
devenv shell
uv run --project scripts --locked jellyfin-people-images --help
devenv tasks run tools:test
```

Devenv provides Python and uv, syncs the editable package, and supplies the
configured Jellyfin URL. Without devenv, use the same `uv run` command with
`--url` or `JELLYFIN_URL` when running an audit.

## Nix packages

```sh
devenv build outputs.homelab-tools
nix build .#homelab-tools
nix run .#jellyfin-people-images -- --help
nix build .#checks.x86_64-linux.homelab-tools
```

`scripts/devenv.nix` defines the outputs once, using devenv's uv2nix importer.
Both devenv and the root flake consume that module. `homelab-tools` is the generic
Python environment; `jellyfin-people-images` wraps its command with a default URL
from the media host's proxy declaration and `common/network.nix`. `--url` and
`JELLYFIN_URL` override that default. API keys are supplied only at runtime.

Flake packages/checks target `x86_64-linux`. Installed commands do not require uv
or devenv. `nix flake check` tests the installed package; `devenv test` additionally
tests the editable project.

## Commands

- [Jellyfin person portraits](jellyfin/README.md): audit images and optionally
  queue refreshes for missing or unreadable portraits.

Add Python modules under `src/homelab_tools`, console entry points under
`[project.scripts]`, and offline tests under `tests`. Keep unrelated scripts in
their own language rather than wrapping everything in Python.
